# 同梱モーションを作って踏んだこと — Blender で VRMA を組む

作り直し方と置き場所は [`../mascot.md`](../mascot.md)「同梱モーションを作り直す」。ここは**作っていて踏んだことだけ**を残す。
道具は `chatter-mascot/motions/`（`vrmalib.py` が共通部品、カテゴリごとに1本のスクリプト）。

## ★ VRMA は回転しか運ばない。手の触れる位置はモデルごとにずれる

VRMA は各骨の回転を持つだけで、アプリはその回転をそのままモデルに当てる。手首の位置で決めたポーズ
（頬に手を添える・お腹の前で手を組む・反対の肘を支える）も、**腕の長さと肩幅の比が違うモデルでは手の行き先が変わる。**
`vita.vrm` で合わせた位置を、肩幅に比べて腕の長いモデルに当てると次のようになった:

- 頬に添えたはずの手が、こめかみまで上がる
- 肘の手前で支えたはずの手が、肘の先へ突き出す
- 指先が触れる程度に組んだはずの手が、指どうし交差してめり込む

★ **同梱モデルだけで合わせない。** 体型の違うモデルにも当てて確かめる（`on_model.py`）。触れるポーズは
「ぴったり」を狙わず、どちらのモデルでも破綻しない位置に置く（指先が軽く触れる程度の間隔、肘の手前、など）。

## ★ 通り抜ける補間は、手が触れたところで行き過ぎる

`smooth()` は区間内のキーのハンドルを AUTO にして、キーで止まらず速度を保ったまま通り抜けさせる
（キーの多い区間がカクつかないように）。**腕にも掛けると、手が頬や肘に着いたキーでも速度が残り、
着いた先へ数フレーム行き過ぎる。** 待機の小ネタで、肘を支えに行った手が胴にめり込んだ。

手当ては、**手が着いて止まるキーを腕の `smooth()` の範囲から外す**こと。胴と頭は通り抜けさせたままでよい
（`idle.py` は腕と胴で `smooth()` の範囲を分けている）。

## ★ 始まりと終わりだけ決めると、補間は肘の通り道を気にしない

回転の補間は、途中で腕が体のどこを通るかを見ない。踏んだのは3つ:

- 下ろした腕から頬へ手を上げる間を補間に任せると、**肘が脇に付いたまま体の後ろを回り**、手は体の横を
  通って「手を振る」ように見えた → 途中に「手を体の前へ出し、肘を斜め下の外へ張る」キーを挟む
- 肘を張りすぎる（肘が肩の高さまで上がる）と**敬礼に見える** → 張るのは斜め下まで
- 下ろした腕を V 字に振り上げる間を補間に任せると、**横を通って一瞬 T ポーズが見える** → 前を通す中間キーを挟む

## ★ 書き出しは回転の無い骨を省く。目・顎と、動かさない指は後処理で外す

VRM Add-on for Blender の VRMA 書き出しは毎フレームをサンプリングし、**レストから回転しない骨は
チャンネルを書かないが、humanBones には載せる。** そのままだと2つ困る:

- **目・顎** —— 視線は `LookAt` が持つので、VRMA に書くと奪い合う（[`mascot-vrm.md`](./mascot-vrm.md)「素材の `.vrma` は別リポジトリで作る」と同じ除外）
- **指** —— `FingerFallbackPoseProvider` は humanBones に**載っていない**指だけを丸める。載ったまま
  チャンネルが無い指は T ポーズの真っ直ぐな指になる（[`mascot-vrm.md`](./mascot-vrm.md)「VRMA に無い指ボーンは identity（T ポーズ）になる」）

`vrmalib.strip_bones` が書き出しの後で両方を humanBones とチャンネルから外す。指を握る・開くモーション
（`with_fingers=True`）だけ指を残す。

## ★ 歩行はアプリが進める速さに合わせる

XR の歩行は、アプリがモデルを「歩幅 × 1周期の歩数 ÷ 周期」の速さで動かす（`XrWalk` の
`StrideMeters` / `StepsPerCycle` / `CycleSeconds`）。**接地中の足がちょうどその速さで後ろへ流れれば足は滑らない**
ので、`walk.py` は同じ3つの値で組む。片方だけ変えると足が滑る。

## ★ 腰を落として足を前へ出すと、重い歩きになる

歩幅を稼ぐために腰を下げ、かかとを体のずっと前に着くと、**足だけ先に出て胴が後から付いてくる**
歩き（のしのし歩く感じ）になる。コマ画像を眺めても原因は絞りにくいが、数値にははっきり出る
（`vita.vrm`、歩幅 0.53m・周期 1.30 秒。Blender 上でボーンの位置から測った）:

| 見るもの | 重い歩き | 直した後 |
|---|---|---|
| かかとが着く瞬間の、前脚の膝 | 31° | 9° |
| その瞬間の足首（股関節から） | 前 24cm / 後ろ 22cm | 前 20cm / 後ろ 26cm |
| 太ももが後ろへ伸びる角度 | 1° | 12° |
| 腰の上下 / 左右の幅 | 5.0cm / 9.0cm | 1.5cm / 4.0cm |
| 肩の回り | ±9° | ±3.5° |

手当ては3つ:

- **かかとが着く位置を体の下へ寄せる**（`FRONT`）。着く瞬間は、前の足より後ろの足のほうを遠くする
- **腰を高く保つ。** 着いた前脚がほぼ伸びる高さを底にして、軸脚の真上を過ぎる頃をいちばん高くする
- **上体を少し前へ倒し、振り出す足は後ろで上げて前へは低く運ぶ。** 前で高く上げて踏み下ろすと行進になる

## ★ 膝は伸びきる手前で、腰の高さの数 mm に振り回される

股関節から足首までの長さは、膝が 5° のときと 15° のときで 6mm しか違わない（`vita.vrm`）。
腰の高さを式で与えて脚を IK で解くと、**腰が 1mm 違うだけで膝が数度動き**、伸びきりに当たった
コマで膝がカクンと止まる。足首も狙った位置に届かなくなる（`walk.py` が書き出しの前に出す
`ik worst error (mm)`）。腰を左右に大きく振ったときに踏み出した脚が届かなくなるのも同じ理由
（腰の横移動を 3cm → 4.5cm にしたとき 8mm 届かなかった）。

手当ては、**伸びきる側を時間の式で決めない**こと:

- **着いた前脚** —— 腰の高さの波を、伸びきりに触れない高さに合わせる。`walk.py` が出す
  `knee (deg)` の `at heel strike` と `min` を見る（脚が届かないか膝が伸びきると、書き出しの前に止まる）
- **後ろへ流れる脚** —— かかとの上げ方を先に決めず、**膝が伸びきる手前（`TRAIL_KNEE`）で止まるよう
  かかとの角度を解く。** 脚が届かなくなったぶんだけかかとが上がり、太ももが後ろへ伸びる。
  時間の式で上げると、早ければ太ももが伸びる前に膝が折れ、遅ければ届かない
- **届くかどうかの境目も滑らかに切り替える**（`SOFT`）。「かかとを上げずに届くか」で切り替えると、
  膝は伸びる速さを保ったまま `TRAIL_KNEE` に当たり、次のコマで止まる（7° でも膝関節の速さが
  1 コマで 8.5mm 変わった。前後のコマは 0.4〜0.6mm）

## ★ 振り出しの両端は、接地の動きを引き継ぐ

床を離れる瞬間と着く瞬間、足はかかと・つま先を支点に回っているので、**足首は床と同じ速さでは
動いていない。** 振り出しを「止まった状態から出て、止まった状態で着く」曲線にすると、両端で
足首の速さが飛ぶ。つま先を支点にして前へ出ていた足首を、離れた後で元の軌道へ戻すと、
足が一度後ろへ流れてから前へ出る。`walk.py` は接地の両端の位置と速さを数値微分で取り、
振り出しをそこへつなぐ。

## ★ 足を外へ向けるなら、支点まわりのずれも同じ向きで回す

足の向きは「傾けてから外へ回す」（`vrmalib` の `feet` の `pitch` と `yaw`）。かかと・つま先を支点に
傾けたときの足首のずれを、向きを入れずに足すと、**床に着いた点が横へ滑る。** つま先を 5° 外へ
向けた `vita.vrm` で、かかとを上げる間につま先の接地点が横へ 7.7mm 動いた（前後は滑らないので、
前後だけを測ると見落とす）。ずれを同じ向きで回すと 0 になる（`walk.py` の `TOE_OUT`）。

## Blender まわりの罠

- **`blender -b --python` はスクリプトが例外で落ちても終了コード 0 を返す。** `--python-exit-code 1` を付ける（`build.sh` はそうしている）
- **Blender 5 の Action は slotted で、`action.fcurves` が無い。** F-Curve は
  `bpy_extras.anim_utils.action_get_channelbag_for_slot(action, slot).fcurves` から取る（`vrmalib.Rig._fcurves`）
- **読み込み直した VRMA のアクションは 1 フレーム目から始まる。** `on_model.py` で描くコマは、書き出したときのフレームに 1 を足して指す
- コンタクトシートは Blender に入っている numpy で並べ、動画は Blender の FFMPEG 出力で書く。外の画像ツールには頼らない
