      Copied once, initially, from cc-mascot's electron/ tree

      Modified independently by chatter-agent ever since. The corresponding
      *.test.ts files are treated the same way. defaultEmotionKeywords.ts
      splits out the keyword-dictionary portion of
      ruleBasedEmotionClassifier.ts.
      The source commit, the mapping table, and how the modifications are
      handled are recorded in docs/origin.md.

      core/src/text/unstableTail.ts, in the same directory, is not derived
      from cc-mascot; it was written from scratch for chatter-agent.

Changes from cc-mascot beyond the above:

  - Replaced the way speech is captured: watching jsonl logs gave way to
    Claude Code's MessageDisplay hook. Accordingly, logMonitor / fileTail /
    adapters / parsers / activeSessionMonitor were not ported.
  - Dropped the Electron main-process / renderer-process structure and
    rebuilt the Mac side as a plain Node.js CLI + WebSocket server.
  - Replaced the delivery of speech messages: Electron IPC gave way to a
    record (speech.jsonl) plus a delivery queue (speech/<seq>.json) +
    WebSocket.
  - Replaced the persistence of settings, from electron-store to JSON files.
  - Did not port the renderer side that handled VRM rendering, speech
    synthesis and lip sync. The display-side client app was rebuilt with
    Unity + UniVRM, and both the macOS desktop app and the Android XR app
    are built from it.

## Third-party assets included in the repository

Placed under `chatter-mascot/Assets/StreamingAssets/`, and included in
the `.app` / `.apk` as well.

  - vita.vrm — AvatarSample_F ("Vita", a legacy sample model on VRoid Hub)
      Author: Coatie (Koh-Tee). **CC0** (public domain).
      **A sample model from the old beta of VRoid Studio**, for which pixiv
      has waived copyright.
      https://vroid.pixiv.help/hc/ja/sections/360002889853
      https://hub.vroid.com/characters/4593660874193246717/models/7942721847119018516
      ★ **The samples from 1.0 onward (VRoidPreset_A-Z) are not CC0.** Do not
        confuse the two.

      ★ **Two fields of the VRM metadata were rewritten before bundling it.**
        VRoid Studio's VRM1.0 export has no CC0 preset, and the defaults it
        converted to conflicted with the asset's license:
            commercialUsage: personalNonProfit -> corporation
            modification:    allowModification -> allowModificationRedistribution
        The rewrite was done with
        `chatter-mascot/scripts/patch-vrm-meta.py`. Only those two
        fields of the glTF JSON chunk are replaced; **the geometry and the
        textures (the BIN chunk) are byte-for-byte as they were.**

  - idle_loop.vrma — public/animations/idle_loop.vrma from kazakago/cc-mascot
      Copyright 2026 kazakago, licensed under the Apache License, Version 2.0.
      https://github.com/kazakago/cc-mascot
      **Unmodified.** The idle motion (→ issue #59).

  - NOTICE.txt — **a copy of this very file** (→ issue #76).
      It exists so that the notice ships inside the `.app` / `.apk`.
      ★ **An EditMode test (NoticeTests) pins the two together.**
      ChatterAgent's settings window shows the repository's NOTICE, embedded
      at build time.
